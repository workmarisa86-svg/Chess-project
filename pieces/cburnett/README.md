# Chess pieces: "cburnett" set

These chess piece images are the **cburnett** set created by
**[Colin M.L. Burnett](https://en.wikipedia.org/wiki/User:Cburnett)**, the classic Staunton-style
set used on Wikipedia and Lichess.

  <https://github.com/lichess-org/lila/tree/master/public/piece/cburnett>
  (credited there as "Colin M.L. Burnett, GPLv2+").

## Changes made for Chess Coach

- `wB.svg` and `bB.svg` (the bishops): the small "+" cross on the mitre was replaced by the
  traditional diagonal slit, so the bishop is recognizable at a glance on small screens.
  Each modified file carries a note saying so.
- All other files are unchanged.

These SVG files are themselves the editable source of the artwork.
